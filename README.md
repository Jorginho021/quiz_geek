# 💻 DevMatch - Quiz Geek

DevMatch é um **quiz interativo sobre perfis de desenvolvedor**.
O objetivo do projeto é permitir que o usuário responda perguntas e descubra qual perfil combina mais com ele dentro do mundo da tecnologia.

O sistema foi desenvolvido utilizando **PHP, HTML e CSS**, com foco em praticar conceitos de desenvolvimento web.

---

# 🎯 Objetivo do Projeto

Criar um quiz simples e interativo que:

* Apresente perguntas relacionadas ao mundo da tecnologia
* Calcule o perfil do usuário
* Mostre um resultado personalizado
* Utilize cookies e sessões em PHP
* Tenha um design moderno com CSS

---

# 🧠 Perfis de Desenvolvedor

O quiz pode identificar os seguintes perfis:

🎨 **Web Designer**
Pessoa criativa focada em interface, experiência do usuário e design visual.

⚙ **Backend Developer**
Especialista em lógica, banco de dados e funcionamento do sistema.

🔁 **Full Stack Developer**
Profissional versátil que trabalha tanto no front-end quanto no back-end.

☁ **DevOps / Infraestrutura**
Focado em servidores, automação, deploy e infraestrutura de sistemas.

# 🚀 Como Executar o Projeto

1. Instale um servidor local (XAMPP, WAMP ou Laragon)
2. Coloque a pasta do projeto dentro de:

```
htdocs
```

3. Inicie o **Apache**
4. Acesse no navegador:

```
http://localhost/devmatch
```
